# ローカル専用カスタム SE フォルダ (`assets/se_custom/`)

このフォルダは、ユーザー個人が所有する効果音ライブラリ（ワンショット WAV 等）を配置して、SSRGenerate の 15 秒ガチャ演出へ自動的に織り込むための**ローカル専用拡張スロット**です。

> [!IMPORTANT]
> **ライセンス保護（OSS 配布時の誤コミット防止）**  
> `.gitignore` により、このフォルダ内の音声ファイル（`.wav` 等）および `slots.json` はすべて Git 管理から除外されます（この `README.md` のみがリポジトリに含まれます）。商用サンプルパック等を配置してもそのまま安全に運用でき、**何も配置されていない場合は 100% プロシージャル合成へ自動フォールバック**します。

### デフォルト動作の違い
- **`layer`（重ね掛け）**: 配置したサンプルを主役に据えつつ、プロシージャル側の低音・和音・残響土台を控えめ（約 45%）に重ねて一体感を保ちます。
- **`replace`（完全差し替え）**: プロシージャル側の該当効果音をミュートし、配置サンプルのみを使用します（和音パッドや背景リバーブ余韻は維持されます）。

## `slots.json` による個別調整（任意）

各スロットの音量や重ね方・開始オフセット・最大尺を細かく調整したい場合は、`assets/se_custom/slots.json` を作成してください（こちらも `.gitignore` 対象です）。

```json
{
  "rainbow_shatter": {
    "mode": "replace",
    "gain": 1.15,
    "offset_sec": 0.0,
    "trim_sec": 2.2
  },
  "card_whoosh": {
    "mode": "layer",
    "gain": 0.9,
    "proc_duck": 0.35
  },
  "star_chime": {
    "mode": "layer",
    "gain": 0.8,
    "offset_sec": -0.01
  }
}
```

### 設定キー一覧
- `mode`: `"layer"`（重ね掛け）または `"replace"`（差し替え）
- `gain`: サンプル再生倍率（例: `1.0` が基準）
- `proc_duck`: `mode: "layer"` 時にプロシージャル側を何倍に抑えるか（デフォルト `0.45`）
- `offset_sec`: 発音タイミングの微調整（秒、負値で早め・正値で遅め）
- `trim_sec`: サンプル最大長の上限（秒、超過分は滑らかにフェードアウト）

npm run render
npm run qa -- renders/ssr_gacha.mp4 --check-audio
